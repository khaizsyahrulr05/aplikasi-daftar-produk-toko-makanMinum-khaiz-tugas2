# Aplikasi sederhana pencatatan produk makanan dan minuman
Aplikasi desktop sederhana untuk mencatat daftar produk toko, dibuat dengan netbeans dan scenebuilder

## Fitur

### 1. Tambah produk lewat form: 
- kode otomatis akan muncul setelah simpan
- nama
- kategori (Makanan/Minuman)
- harga
- gambar bersifat opsional (bisa ada bisa null)
### 2. Tabel daftar produk: 
- gambar ukuran kecil (jika melampirkan)
- kode
- nama produk
- kategori
- harga
### 3. Cari produk berdasarkan nama lewat tombol Cari, tombol Reset untuk menampilkan semua
### 4. Tombol Lihat Detail membuka halaman detail produk yang dipilih
### 5. Validasi: nama tidak boleh kosong dan harga harus lebih dari nol
### 6. Data disimpan di memori, jadi hilang saat aplikasi ditutup (tanpa database)

## Cara menjalankan
1. Pilih projek yang ingin dibuka
2. Klik kanan projek
3. Klik run
4. selesai
